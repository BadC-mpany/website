# Bad Company

Website for Lilith: mandatory access control for AI agents.

## Development

```bash
bun run dev
```

Open http://localhost:3000

## Build

```bash
bun run build
bun run start
```

## Surfaces

```
/                 NAME / SYNOPSIS / DESCRIPTION
/lilith           kernel product
/lilith/zero      Apache 2.0 SDK
/notes            writing
/people           names
```

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Bun
